# 觀象科技一頁式官方網站

這是可直接部署到 GitHub Pages 的純靜態網站，不需要安裝套件或執行建置指令。

## 部署方式

1. 將本資料夾中的 `index.html` 與 `styles.css` 上傳至 GitHub repository 的根目錄。
2. 在 repository 的 **Settings → Pages** 中，選擇 **Deploy from a branch**。
3. Branch 選擇 `main`，資料夾選擇 `/ (root)`，儲存後等待 GitHub Pages 發布。
